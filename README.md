# 456tv 쇼츠 스튜디오 · Windows 베타

사진에 장면 효과, 전환, 텍스트와 음악을 넣어 쇼츠를 만들고 MP4로 저장하는 Windows용 편집기입니다. 영상과 사진은 내 PC에서 처리합니다.

## 다운로드와 설치

1. [GitHub Releases](https://github.com/rasin21/456tv-shorts-studio/releases)에서 가장 최근 베타를 열고, **Assets**의 `456tv-Studio-…-win-x64.zip`을 내려받습니다. Windows 11 x64에서 검증했습니다.
2. ZIP을 원하는 폴더에 **모두 압축 풀기**로 풉니다. 같은 폴더의 `456tv.exe`와 `resources` 등 구성 파일은 함께 둡니다. 앱 실행에는 Node.js가 필요하지 않습니다.
3. 레퍼런스 영상 분석이나 MP4 저장을 하려면 폴더 안의 **`Install-FFmpeg.cmd`**를 한 번 실행합니다. 인터넷 연결이 필요합니다. 설치 도구가 Gyan Windows 빌드의 FFmpeg와 ffprobe를 받아 SHA-256을 검증한 뒤 현재 앱 폴더에 설치합니다.
4. 설치 도구에 `FFmpeg is ready`가 표시되면 **`456tv.exe`**를 실행합니다.

베타에는 456tv 게시자 코드 서명이 적용되지 않았습니다. Windows에서 실행 파일의 출처를 확인하라는 메시지가 표시될 수 있습니다. 다운로드는 위 공식 Releases 링크를 사용하세요. 파일을 확인하려면 함께 제공한 `.sha256`과 PowerShell의 `Get-FileHash -Algorithm SHA256 <ZIP 파일>` 결과를 비교하세요.

## 사용법

1. **이미지 추가**에서 사진을 최대 6장 등록하고 왼쪽 목록에서 순서를 조정합니다.
2. **효과**에서 장면 길이, 사진 효과, 장면 전환, 이미지 맞춤을 조절합니다. **텍스트**와 **음악**에서 제목·설명·456tv 브랜딩과 배경음악을 설정합니다.
3. **미리보기**에서 재생해 보고 **MP4 내보내기**를 누릅니다. 저장한 영상은 **완성 영상 확인**에서 다시 재생할 수 있습니다.
4. 자주 쓰는 설정은 **제작 템플릿 저장**을 누릅니다. 이후 **편집 설정 → 템플릿**에서 이름을 골라 적용할 수 있습니다. 원본 사진이나 음원 파일은 템플릿에 포함되지 않습니다.

**레퍼런스 영상**이 있다면 왼쪽 프로젝트 이름 아래의 **영상 업로드**에서 선택하세요. 처음 3분의 컷 후보를 확인한 뒤 원하는 구간의 길이를 사진에 적용할 수 있습니다. 빈 프로젝트에서는 구간별 대표 이미지로 바로 편집을 시작할 수 있습니다.

**대량 생성**에서는 사진 폴더를 등록하거나 CSV 양식을 사용합니다. 폴더마다 한 편씩 저장되며, 실패한 작업만 다시 시도할 수 있습니다.

## 베타 업데이트

[Releases](https://github.com/rasin21/456tv-shorts-studio/releases)에서 새 베타 ZIP을 내려받습니다. 기존 앱 창을 닫고 새 폴더에 압축을 푼 뒤 `Install-FFmpeg.cmd`를 실행하고 새 `456tv.exe`를 엽니다. 같은 Windows 사용자 계정에 자동 저장한 프로젝트와 제작 템플릿은 새 버전에서 불러옵니다. 프로젝트에 등록한 사진과 음원은 원래 위치에 두세요.

문제가 생기면 [Issues](https://github.com/rasin21/456tv-shorts-studio/issues)에 베타 버전, Windows 버전, 문제가 생긴 단계, 화면에 나온 메시지를 남겨 주세요.
